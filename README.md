# 萌萌星语（astrbot_plugin_moe_star_whisper）

AstrBot 今日运势插件：每个用户每天一支专属「星语签」——AI 可选底图 + 萌系图卡 + 签文话语 + 萌化宜忌 + 星座与道具经济 + 运势日历。

## 特性

- **每日确定论**：运势由 `SHA-256(日期|用户|盐|nonce)` 确定性推导，一天一签、跨群/私聊全局一致；当天重复请求直接回发已存卡片，零生成成本。
- **签面内容**：吉凶六档（大吉→大凶，权重可配）、六维星数 + 幸运指数、幸运物/色/数字/方位、宜忌各两条、签文话语（点评 + 幸运物联动 + 祝语）。
- **萌系图卡**：Pillow 本地渲染，运势卡配色由幸运色驱动（每天不同观感）；提示卡/帮助图支持多主题（跟随默认 / 亮色 / 暗色 / **塔罗牌** / 樱花 / 薄荷——边框与四角装饰随主题一起变），榜单带 QQ 头像；字体不打包、多级查找。
- **星尘上卡**：占卜结果图标注「今日星尘 +N ｜ 累计 M」；星尘钱包/道具商店/星语榜/PK/购买与使用结果/生日绑定/星座查询均以同风格提示卡展示（`仅文字` 模式回到文本）。
- **运势日历**：`/星语日历 [月份]` 渲染当月真实月历——每日吉凶（档位色）+ 幸运指数，未占卜画小点、今日金框，附本月占卜统计。
- **AI 星象底图**（可选）：安装[萌绘](https://github.com/windExplorer/astrbot-comfyui-anima)（`astrbot-comfyui-anima`）后，LLM 依当日运势生成英文标签提示词，萌绘出图作为卡面底图；seed/尺寸透传，失败自动回退渐变底图。
- **LLM 星语**（可选，默认关）：当日首次抽签由 LLM 按运势事实清单改写签文，失败回退本地词库。
- **星座与彩蛋**：生日绑定（只存月日）、星座角标、生日必大吉+金环卡面、愚人节整活、节日词库池、周五摸鱼加成、连签徽章。
- **道具经济**：星尘积分（每签必得、越倒霉补偿越多）+ 换签卡/厄运护身符/幸运香烛/连签保护卡四道具；全流水落库，不可转账不可兑换。
- **群玩法**：`/星语榜`（日/周，按**本群成员**统计——人在本群就上榜，哪怕今天是在别的群抽的签；取不到成员列表时回落「本群抽签」口径并在标题标明；**上榜人数可配**（3-50，见「榜单人数」），每行带一枚**吉凶徽章**）、`/星语PK`、群开关、连签徽章。
- **数据全量落库**：SQLite 于 `data/plugin_data/astrbot_plugin_moe_star_whisper/star_whisper.db`（抽签/档案/绘图任务/星尘流水），为统计功能预留口径。
- **WebUI 控制台**（v1.9.0）：Vue3 + Naive UI + ECharts 面板（插件 Page `pages/console/`）——总览指标与趋势、抽签记录检索、**抽过签的用户列表（头像/QQ/昵称，点开看单用户档案与运势日历）**、六维/幸运物/星座统计、**群聊使用分布（占比 + 群活跃榜）**、参数配置分区读写、调试工具（重抽/重绘/重置）；另有单文件旧调试页 `pages/debug/` 可回退。
  > 群聊口径：每条记录 = 用户**当天第一次抽签所在的那个群**（一日一签 + 换群不再写新行），所以一人一天只计入一个群，不会重复计算；私聊单独统计。
  > 群名会随抽签一起入库（优先取事件自带群名，兜底调平台 API），历史记录没有群名时用「该群最近一次记录到的群名」回填，仍拿不到才显示群号。

## 配置

`_conf_schema.json` 全量键位（AstrBot 配置页自动生成）：时区、盐值、吉凶权重、输出方式、卡面主题/字体/尺寸、LLM 星语、每日推送（时间/开关）、萌绘联动（工作流/提示词语言与形式/超时）、**榜单人数**、道具价格等。

榜单人数（`rank_size`，默认 10）：`/星语榜` 日榜与周榜最多显示多少人（3-50）。榜单每行都会带一枚吉凶徽章——日榜是当天那一签、周榜是本周最近一签，两榜口径统一为「他最近一签的吉凶」。

每日推送（`daily_push_enabled` 默认关 + `daily_push_time` 默认 `08:00`）：到点给「近 7 天有抽签、且未停用」的群发一条「今日星象」卡——日期/星期（右上角小字带年份）、月相与文案、**农历**（含干支生肖，如「八月十五 · 丙午马年」）、**节日**（公历 + 农历节日，有则显示，可撞同天一起发）、**节气**（24 节气当天才有，带词库文案）、**今日宜忌**（宜 2 忌 2）、**今日幸运**（幸运色色块 + 幸运数字 + 幸运方位）、**本群昨日抽签摘要**（如「昨日本群 23 人抽签 · 最吉：小明（大吉 96）」）、底部指令引导。卡高度随内容自动加高，渲染失败时这些内容会回落到文字里，不会丢。

**两个种子、两种内容**：客观历法（日期/星期/月相/农历/节气/节日文案）由 `日期 + salt` 派生，**同一天所有群一致**（天上只有一个月亮，月相各群不一样会露馅）；本群的运势黄历（**今日宜忌、幸运色/数字/方位，以及卡片主色**）由 `日期 + 群号 + salt` 派生，**每个群各不相同**——所以不同群的星象卡配色和宜忌一眼就能看出不是同一张图；再叠上各自的「昨日摘要」，这就是一张**本群专属**的卡。

农历与节气**不依赖任何第三方库**：插件的 `lunar.py` 自带 1900-2100 年的农历压缩表与「寿星公式 + 36 条例外」的节气算法，两份数据都用 `lunar_python` 在 1900-2100 逐日交叉验证过（73,384 天全一致）。原因很实际：AstrBot 装插件时会执行 `requirements.txt`，装失败会让插件直接装不上——卡上两行小字不值得冒这个风险。节日文案与节气文案都放在词库（`festivals` / `lunar_festivals` / `jieqi`）里，可自行改。

不想等定时、也不想真开推送时，随时发 `/星语星象` 就能让同一张卡立刻出现（与该群的推送**逐字一致**；私聊也能用，只是没有群可算，「本群昨日摘要」整行省略）。这条指令**直发、不进结果链**，所以群里**不会 @ 发送者**。

推送与 `/星语星象` 都跟随配置**「出签方式」**：默认**「萌系图卡」只发卡片图片**（指令引导本来就画在卡上）、「图卡加文字」图 + 文、「仅文字」不发卡（本群数据/宜忌/幸运/农历/节气全部回落到文字里）。

## 字体说明（图卡）

字体不打包、也不依赖其它插件，只认两个位置：

1. **AstrBot 的公共字体目录 `data/fonts/`**（推荐——放这里所有插件都能用）；
2. 本插件数据目录的 `data/plugin_data/astrbot_plugin_moe_star_whisper/fonts/`。

两处都没有可用字体时继续走系统字体（Windows 微软雅黑 / Linux Noto CJK）；全都没有则回退纯文本出签。支持 `ttf / otf / ttc / woff2`（woff2 需 Pillow 所带 FreeType 支持 brotli，读不了的候选会被自动跳过）。

**字体选择**（配置 `card_font_style`，一个开关三选一）：

| 取值 | 效果 |
| --- | --- |
| `默认（黑体 + 楷体）` | 正文黑体 + 展示文字（吉凶/牌名/大数字）楷体 |
| `圆体` | 全卡统一圆体——在候选目录里挑文件名含 `rounded` 的字体 |
| `自定义` | 使用「自定义字体」`card_font_path`（**选了它才会出现这一项**） |

「自定义字体」支持三种写法（写法 ①② 在候选目录里找）：

| 写法 | 例子 |
| --- | --- |
| 字体名（最省事，忽略大小写/空格/连字符） | `Resource Han Rounded`、`resourcehanrounded` |
| 文件名（忽略大小写） | `ResourceHanRoundedCN-Medium.woff2` |
| 文件路径（绝对路径最稳，相对路径按 AstrBot 进程工作目录解析） | `/AstrBot/data/fonts/ResourceHanRoundedCN-Medium.woff2` |

选「圆体」但目录里没有圆体（或本机读不了该格式）、选「自定义」但字体留空或解析不到时，都会**在日志里给出具体原因**（没有这个文件 / 有匹配但本机读不了 / 路径不存在）并回落默认字体，不会导致出卡失败。圆体推荐 [Resource Han Rounded](https://github.com/CyanoHao/Resource-Han-Rounded)（SIL OFL 1.1，文件名形如 `ResourceHanRoundedCN-Medium.woff2`）；字体名不含 `rounded` 的（例如 LXGW WenKai 霞鹜文楷）用「自定义」填进去即可。

## 依赖

- AstrBot 4.28+
- `pillow`（图卡）
- `tzdata`（时区；缺省环境自动回退 UTC+8）
- 萌绘（`astrbot-comfyui-anima`）底图联动需另装该插件并开启 `draw_enabled`

## 开发

```powershell
# 运行测试（核心模块无 astrbot 运行时依赖，直接跑；退出码即结论）
uv run --no-project python tests/test_lexicon.py
uv run --no-project python tests/test_fortune.py
uv run --no-project python tests/test_lunar.py
uv run --no-project python tests/test_store.py
uv run --no-project --with pillow python tests/test_card.py
uv run --no-project python tests/test_main_structure.py

# 农历/节气数据的来源与交叉校验（可选依赖 lunar_python，不在日常测试里）
uv run --no-project --python 3.12 --with lunar_python python tests/_tools/lunar_oracle.py

# 打包（产物在 dist/，同名版本已存在会拒绝打包）
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_zip.ps1
```
